    \begin{center}

\end{enumerate}

\section*{2. Mathematical Formulation of Naive Bayes}
\noindent\rule{\textwidth}{0.6pt}\vspace{0.15cm}

The Naive Bayes classifier is a probabilistic machine learning algorithm grounded in \textbf{Bayes' Theorem}. Given an SMS message represented as a vector of word tokens $\mathbf{x} = (w_1, w_2, \dots, w_n)$, the posterior probability of the message belonging to class $C_k \in \{\text{ham}, \text{spam}\}$ is given by:

\begin{equation}
    P(C_k \mid \mathbf{x}) = \frac{P(C_k) \cdot P(\mathbf{x} \mid C_k)}{P(\mathbf{x})}
\end{equation}

Assuming the conditional independence of words given the class label:
\begin{equation}
    P(\mathbf{x} \mid C_k) = \prod_{i=1}^{n} P(w_i \mid C_k)
\end{equation}

The classification decision rule assigns the class that maximizes the posterior likelihood:
\begin{equation}
    \hat{y} = \arg\max_{C_k} P(C_k) \prod_{i=1}^{n} P(w_i \mid C_k)
\end{equation}

To avoid the zero-frequency problem where an unseen word forces the entire likelihood product to zero, \textbf{Laplace Smoothing} ($\alpha = 1$) is employed:
\begin{equation}
    P(w_i \mid C_k) = \frac{N_{k, i} + \alpha}{N_k + \alpha \cdot |V|}
\end{equation}
where $N_{k,i}$ is the count of word $w_i$ in class $C_k$, $N_k$ is the total count of words in class $C_k$, and $|V|$ denotes the vocabulary size.

\section*{3. Methodology \& Implementation Architecture}
\noindent\rule{\textwidth}{0.6pt}\vspace{0.15cm}

\noindent
\begin{minipage}[t]{0.50\textwidth}
\textbf{Dataset Exploration:}
\vspace{0.1cm}

The SMS Spam Collection consists of $5,572$ tagged SMS messages. The distribution reflects standard real-world imbalance:
\begin{itemize}
    \item \textbf{Legitimate (Ham):} $4,825$ messages ($86.6\%$)
    \item \textbf{Unsolicited (Spam):} $747$ messages ($13.4\%$)
\end{itemize}

\vspace{0.2cm}
\textbf{Pipeline Stages:}
\begin{enumerate}
    \item \textbf{Text Normalization:} Converting messages to lowercase, stripping punctuation via translation tables, and eliminating numeric digits.
    \item \textbf{Stratified Splitting:} An $80\%-20\%$ train-test split ($4,457$ training records, $1,115$ test records) maintaining identical class proportions across both splits.
    \item \textbf{Bag-of-Words Vectorization:} Tokenizing corpus with \texttt{CountVectorizer}, resulting in a feature vocabulary of $7,537$ distinct unigrams.
    \item \textbf{Model Training:} Fitting \texttt{MultinomialNB(alpha=1.0)}.
\end{enumerate}

\noindent\textbf{Execution \& Prediction Pipeline:}
\begin{enumerate}
    \item \textbf{Raw Input:} \texttt{"Congratulations! You have won a free ticket. Call now!"}
    \item \textbf{Cleaned Token Sequence:} \texttt{"congratulations you have won a free ticket call now"}
    \item \textbf{Vectorized Representation:} Transformed through the fitted vocabulary, matching high-frequency spam trigger unigrams: \texttt{"congratulations"}, \texttt{"won"}, \texttt{"free"}, \texttt{"ticket"}, \texttt{"call"}, \texttt{"now"}.
    \item \textbf{Model Output Class:} \textbf{\large \textcolor{red}{SPAM}}
    \item \textbf{Class Probability Distribution:}
    \begin{itemize}
        \item $P(\text{Spam} \mid \text{Message}) = \mathbf{99.9868\%}$
        \item $P(\text{Ham} \mid \text{Message}) = \mathbf{0.0132\%}$
    \end{itemize}
\end{enumerate}

\noindent\textbf{Result Analysis:}\\
The high concentration of marketing, prize solicitation, and urgency terms yielded a conditional probability overwhelmingly favoring the spam class ($>99.98\%$). The model successfully and decisively identified the malicious nature of the message.

\section*{6. Discussion \& Conclusion}
\noindent\rule{\textwidth}{0.6pt}\vspace{0.15cm}

\begin{itemize}
    \item \textbf{Algorithmic Efficiency:} Multinomial Naive Bayes demonstrates exceptional computational efficiency during both training and inference, completing feature transformations and model fitting across over $5,500$ records in sub-second intervals.
    \item \textbf{Precision vs. Recall Trade-off:} In SMS spam filtering, precision is paramount; false positives (labeling critical legitimate messages as spam) are significantly more detrimental to user experience than occasionally allowing spam through. Achieving a $97.78\%$ spam precision satisfies this practical engineering requirement.
    \item \textbf{Conclusion:} The experiment validated the efficacy of the Naive Bayes algorithm in processing textual data for binary classification. The pipeline successfully ingested the SMS Spam Collection dataset, completed end-to-end preprocessing, achieved an overall accuracy of $98.21\%$, and correctly flagged the test query with extreme certainty.
\end{itemize}
