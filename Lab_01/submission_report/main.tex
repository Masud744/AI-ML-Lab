\section*{1. Problem Statement and Objectives}
\noindent\rule{\textwidth}{0.5pt}\vspace{0.2cm}

Short Message Service (SMS) spam is an ongoing security and user experience challenge in mobile telecommunications. The goal of this laboratory session is to build a machine learning pipeline that automatically identifies whether an incoming SMS is legitimate (\textit{ham}) or spam, using the Naive Bayes classification algorithm.

\vspace{0.2cm}
\noindent\textbf{Assigned Tasks:}
\begin{enumerate}
    \item Load and examine the SMS Spam Collection dataset.
    \item Clean and preprocess message text (lowercase transformation, punctuation removal, tokenization).
    \item Convert raw text into numerical features using Bag-of-Words vectorization.
    \item Train a Multinomial Naive Bayes classifier on a stratified training split.
    \item Test the model on unseen data and report standard evaluation metrics (Accuracy, Precision, Recall, and Confusion Matrix).
    \item Predict the class for the specific test message:
    \begin{quote}
        \textit{``Congratulations! You have won a free ticket. Call now!''}
    \end{quote}
\end{enumerate}

\section*{2. Mathematical Background of Naive Bayes}
\noindent\rule{\textwidth}{0.5pt}\vspace{0.2cm}

The Naive Bayes classifier is built on Bayes' Theorem with the naive assumption of conditional independence among feature terms given the target class. 

For an SMS message represented as a sequence of words $\mathbf{w} = (w_1, w_2, \dots, w_n)$, the posterior probability of belonging to class $c \in \{\text{ham}, \text{spam}\}$ is expressed as:
\begin{equation}
    P(c \mid \mathbf{w}) = \frac{P(c) \cdot P(\mathbf{w} \mid c)}{P(\mathbf{w})}
\end{equation}

By assuming words occur independently given the class label:
\begin{equation}
    P(\mathbf{w} \mid c) = \prod_{i=1}^{n} P(w_i \mid c)
\end{equation}

The predicted class $\hat{c}$ is the one that yields the highest posterior probability:
\begin{equation}
    \hat{c} = \arg\max_{c \in \{\text{ham}, \text{spam}\}} P(c) \prod_{i=1}^{n} P(w_i \mid c)
\end{equation}

In practice, if a word from the test set never appeared in the training set for a particular class, $P(w_i \mid c)$ would evaluate to zero, making the entire product zero. To prevent this, \textbf{Laplace smoothing} ($\alpha = 1$) is used:
\begin{equation}
    P(w_i \mid c) = \frac{N_{c, i} + \alpha}{N_c + \alpha \cdot |V|}
\end{equation}
where $N_{c,i}$ is the count of word $w_i$ in class $c$, $N_c$ is the total count of words in class $c$, and $|V|$ is the total number of unique words across the training corpus.

\section*{3. Methodology and Preprocessing Pipeline}
\noindent\rule{\textwidth}{0.5pt}\vspace{0.2cm}

\noindent\textbf{Dataset Overview:}\\
The experiment uses the SMS Spam Collection dataset, containing $5,572$ labeled text messages. As typical in real-world spam detection datasets, the classes are imbalanced:
\begin{itemize}
    \item \textbf{Ham (Legitimate):} $4,825$ messages ($86.6\%$)
    \item \textbf{Spam (Unwanted):} $747$ messages ($13.4\%$)
\end{itemize}

\vspace{0.1cm}
\noindent\textbf{Text Preprocessing Steps:}
\begin{enumerate}
    \item \textbf{Case Folding:} All characters were converted to lowercase so that words like \texttt{Free}, \texttt{FREE}, and \texttt{free} are treated as the same token.
    \item \textbf{Punctuation and Digit Removal:} Special symbols, punctuation marks, and digits were stripped to reduce noise in the vocabulary.
    \item \textbf{Whitespace Cleanup:} Consecutive whitespace characters were condensed into single spaces.
\end{enumerate}

\vspace{0.1cm}
\noindent\textbf{Feature Extraction and Model Fitting:}
\begin{itemize}
    \item The preprocessed messages were partitioned using an \textbf{80-20 stratified split} ($4,457$ training records and $1,115$ testing records), preserving the original class distribution in both sets.
    \item \texttt{CountVectorizer} was fit on the training split to produce Bag-of-Words feature vectors, discovering a vocabulary of $6,830$ unique words.
    \item A \texttt{MultinomialNB} model was trained on the vector representations.
\end{itemize}

\noindent\textbf{Analysis of Results:}
\begin{itemize}
    \item \textbf{False Positives:} Out of $966$ legitimate messages in the test set, only $3$ messages ($0.3\%$) were mistakenly classified as spam. This gives a spam precision of $97.83\%$. In email and SMS filtering, avoiding false positives is critical because legitimate messages should rarely be lost to spam filters.
    \item \textbf{False Negatives:} Out of $149$ actual spam messages, $14$ were misclassified as ham (giving a recall of $90.60\%$). These typically consist of very brief messages or texts without standard spam promotion terms.
\end{itemize}
